01

What is Thermodynamics?

Thermodynamics adalah cabang ilmu yang mempelajari hubungan antara energi, panas, kerja, dan perubahan keadaan suatu sistem.

Dalam thermodynamics, kita tidak hanya mempelajari bagaimana energi berpindah, tetapi juga bagaimana energi tersebut berubah dari satu bentuk ke bentuk lainnya.

03

Types of Thermodynamic Systems

Berdasarkan perpindahan massa dan energi, system dapat diklasifikasikan menjadi tiga jenis utama.

🌬️

Open System

Massa dan energi dapat melewati boundary system.

Example:

Turbine, compressor, pump.

📦

Closed System

Massa tidak dapat melewati boundary, tetapi energi dapat berpindah.

Example:

Piston-cylinder system.

❄️

Isolated System

Tidak ada massa maupun energi yang melewati boundary.

Example:

Idealized thermos.

04

Properties of a System

Property adalah karakteristik yang dapat digunakan untuk menggambarkan keadaan suatu system.

Intensive Property

Tidak bergantung pada jumlah massa dalam system.

Examples: Temperature, pressure, density.

Extensive Property

Bergantung pada jumlah massa dalam system.

Examples: Mass, volume, total energy.

05

State & Equilibrium

State adalah kondisi suatu system yang dapat dijelaskan menggunakan sejumlah property tertentu.

Misalnya, keadaan suatu gas dapat dijelaskan melalui pressure, temperature, dan volume.

Thermodynamic Equilibrium

Suatu system berada dalam equilibrium ketika tidak terdapat perubahan spontan pada kondisi makroskopiknya.

06

Thermodynamic Process

Thermodynamic process adalah perubahan suatu system dari satu state ke state lainnya.

Contohnya adalah proses pemanasan gas, ekspansi gas, kompresi gas, dan perubahan fase suatu zat.

SUMMARY

Key Takeaways

  • Thermodynamics mempelajari energi, heat, work, dan perubahan keadaan.
  • System adalah bagian yang dianalisis, sedangkan surroundings berada di luar system.
  • System dapat berupa open, closed, atau isolated system.
  • Properties dapat diklasifikasikan menjadi intensive dan extensive.
  • State menggambarkan kondisi suatu system.
  • Process menggambarkan perubahan dari satu state ke state lainnya.
